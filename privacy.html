Политика конфиденциальности

Приложение — личный OAuth-клиент, используемый одним человеком (владельцем аккаунта) для доступа к своему Google Drive с одного компьютера через rclone. Других пользователей у приложения нет.

  • Приложение не собирает персональные данные и не имеет регистрации.
  • Данные, полученные через Google Drive API, используются только для чтения и записи файлов владельца на его компьютере и не передаются третьим лицам.
  • Токены доступа хранятся локально в файле ~/.config/rclone/rclone.conf с правами 0600 на одном компьютере.
  • Данные Google не используются для рекламы, аналитики и обучения моделей.
  • Использование данных, полученных через Google API, соответствует Google API Services User Data Policy, включая требования Limited Use.
  • Отзыв доступа: myaccount.google.com/permissions.
